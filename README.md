# Libre AI Organization Data Lifecycle

[Français](README.fr.md)

Retention, deletion and restoration need consistent rules across the places where a product stores data. This project explores data lifecycle management for application and data-platform developers. Its focus is following a defined organization scope across multiple stores, including what happens when older data returns through a backup.

## Intended uses

- Apply an explicit retention rule to a selected category of organization data.
- Follow a scoped deletion request across the stores that hold that data.
- Restore a backup while accounting for data that should remain deleted.

## Availability

Source code and tests are available in this repository; no package is published to a registry.
