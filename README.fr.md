# Libre AI Organization Data Lifecycle

[English](README.md)

La conservation, la suppression et la restauration demandent des règles cohérentes entre les stockages d’un produit. Ce projet explore le cycle de vie des données pour les développeurs d’applications et de plateformes. Il suit un périmètre d’organisation défini entre plusieurs stockages, y compris lors du retour de données anciennes par une sauvegarde.

## Usages visés

- Appliquer une règle de conservation explicite à une catégorie de données d’organisation.
- Suivre une demande de suppression délimitée dans les stockages concernés.
- Restaurer une sauvegarde en tenant compte des données qui doivent rester supprimées.
